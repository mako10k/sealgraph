## 承認された要件の要点

- 大きな既存文書を物理的に分割せず、小さな Seal と、コンテンツのバイト範囲ごとの由来を扱う。
- 複数の元ファイル由来の範囲と Seal 独自表現を混在させ、過去の由来と現在の元ファイルとの比較を区別する。
- 必要に応じて抜粋を中間 Seal とし、別の Seal がその正確な Seal 世代全体を Cause として参照する。
- Trace 比較で一致・差異・判定不能を区別し、自身・上流側・下流側の観測を独立して保持・表示する。
- 差異と判定不能の併存を許し、直接・間接の関係、該当する Seal 世代と範囲、Cause の経路、観測範囲を示す。
- 関係の集計に exact Cause target を用い、集計結果を上流・下流へ往復させない。
- Cause Link の対象と既存 STALE の定義を維持し、構造的な検証を行う一方、コンテンツや Cause の意味論を監査しない。
