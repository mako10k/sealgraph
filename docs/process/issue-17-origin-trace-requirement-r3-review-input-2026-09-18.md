## 対象と除外

対象は External run の P について、記録 `source_start` を有効な一件かつ探索ヒントとして保持し、元版 S・現在版 F の必要な側から `Occ(B,P)` を導出する能力である。全位置は永続記録しない。位置一覧・位置に基づく提案は既定件数上限とページングを持つ。Seal 時点の元ファイル全文は、Seal 範囲外も含めて後から exact bytes で復元可能とする。R2 の一件命中による原文残存、全域確認による不存在、未完了の区別はそのまま残す。

対象外は実編集履歴・唯一の由来・意味の保存の証明、内容や Cause の意味論監査、STALE の変更、whole-Seal Cause の変更、変更後範囲推定の具体方式、位置一覧の CLI 名・schema・既定件数・ページ識別子・数値性能保証である。これらは候補の暗黙の受入条件ではない。公開契約に必要な詳細は要件採用後の設計判断へ送る。
