# sealgraph v0.1.0-beta.1

First standalone beta for Linux amd64.

## Included

- format-4 immutable Seals, exact Cause links, branching revision parents,
  logical REFs and immutable scoped tags;
- explicit candidate review and one-REF publication;
- stale/frontier, impact, graph, history, semantic diff, and versioned JSON;
- exact file/stdin content ingestion and deterministic explicit-path manifests;
- explicit format-3 logical dump / format-4 empty-target load boundary;
- read-only full-inventory `fsck`.

## Deliberately not included

- file synchronization, watchers, working-tree comparison, or automatic import;
- Git discovery, Git hooks, or `git-sealgraph`;
- `attach` / `detach` mutation commands;
- automatic relink, recursive repair, batch sealing, signatures, remote
  storage, daemon, server, or trust assertions.

Formats 1 through 3 are not opened by the beta runtime. Conversion requires
the matching historical format-3 dump binary and an explicit format-4 load
into an absent target. This is a prerelease; public CLI and storage
compatibility remain subject to documented pre-1.0 changes.
