# sealgraph v0.1.0-beta.2

Second standalone beta for Linux amd64.

## Included in this update

- registry-backed root, command, and nested-command help;
- `help selectors`, `help concepts`, and `help usecases` domain navigation;
- command-local `--help` generated from the same help definitions;
- usage diagnostics with accepted syntax, correction hints, and help routes;
- invariant diagnostics that explain explicit inspection/review actions without
  automatic relink, reseal, repair, or REF selection;
- safe display-only command typo suggestions.

Successful command JSON schemas and native repository format 4 are unchanged.
Errors remain human-readable stderr; this release does not introduce stable
diagnostic codes or a JSON error schema.

## Retained standalone scope

This prerelease remains Linux amd64 and standalone-only. It does not add file
synchronization, Git discovery or sidecar behavior, attachment mutation,
automatic repair, signatures, remote storage, daemon/server behavior, or trust
assertions.
