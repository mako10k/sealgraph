# sealgraph v0.1.0-beta.3

Third standalone beta for Linux amd64.

## Included in this update

- explicit non-canonical local REF-to-file source bindings through
  `source bind`, `show`, `list`, `rebind`, and `unbind`;
- contentless `add REF` refresh from an existing binding;
- initial `REF=path` content import, with optional `--bind-source`;
- content-only refresh that preserves candidate/HEAD semantics unless an
  explicit mutation option names a change;
- status v2 with separate candidate-to-HEAD and workfile-to-baseline axes;
- safe changed-during-read, missing-source, unsafe-source, and binding-conflict
  failures with explicit next actions;
- aligned command help, error navigation, requirements, architecture, CLI,
  storage, integration, and operator documentation.

## Retained standalone scope

Source bindings are machine-local input configuration. They are excluded from
Seal identity, canonical REF state, logical dump/load, and canonical fsck.
This prerelease does not watch files, automatically add or seal changes,
restore binding history, discover Git, or implement `git-sealgraph` behavior.
It also does not add attachment mutation, automatic repair, signatures, remote
storage, daemon/server behavior, or trust assertions.

This is a prerelease. Public CLI and storage compatibility remain subject to
documented pre-1.0 changes.
